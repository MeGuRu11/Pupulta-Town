# 0001. Город = проект, задача = объект по размеру

Дата: 2026-10-27. Решили владельцы проекта.

## Решение

- Город — это проект команды. У человека может быть несколько городов. В городе до 20 участников.
- Задача становится объектом по размеру: S — мелкий объект (ларёк, фонарь, клумба), M — дом, L — большое здание, которое достраивается по подзадачам.
- Монеты за задачи тратятся на декор, улицы и жителей.
- Мир трёхмерный, работает в браузере на компьютере. Телефоны не поддерживаем.
- Модели делаем сами в Blender. Кастомизация детальная, через модульные наборы: здания, люди, одежда, машины, животные.
- Камера: общий фиксированный ракурс с поворотом, здания видны со всех сторон.
- Прогулки своим аватаром будут позже, но архитектуру под них закладываем сразу.

## Почему

По городу сразу видно состояние работы, и при этом остаётся свобода его украшать. Подробности и рассмотренные варианты в [concept.md](../concept.md).
