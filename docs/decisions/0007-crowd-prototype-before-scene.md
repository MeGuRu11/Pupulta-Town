# 0007. Прототип толпы делаем перед 3D-сценой, а не до всего среза

Дата: 2026-10-28. Решил владелец проекта.

## Решение

Первый срез идёт в порядке из [плана](../plans/2026-10-28-first-slice.md): PR 1–4 (каркас, симуляция, база, интерфейс трекера), затем прототип толпы, затем PR 5–6 (3D-сцена и сквозной тест).

## Почему

`architecture.md` ставит прототипы перед разработкой, потому что прототип толпы решает, остаётся ли Three.js. Из шести PR среза движок затрагивает только PR 5. Если прототип стоит прямо перед ним, он по-прежнему может отменить выбор движка до кода сцены и при этом не держит остальную работу.

## Что из этого следует

- PR 5 не начинается, пока итог прототипа толпы не записан в `docs/decisions/`.
- Прототип можно делать параллельно с PR 1–4, например товарищем.
