# 0013. Рабочая среда проекта на Codex

Дата: 2026-11-06. Решил владелец проекта. Заменяет настройку из [0006](0006-ai-environment.md).

## Решение

1. Для работы с ИИ-агентами в проекте используем Codex. Общие инструкции остаются в `AGENTS.md`, проектные скиллы — в `.agents/skills/`. Конфигурация MCP, роли и локальный хук находятся в `.codex/`.
2. В доверенном проекте Codex может загружать общие Context7, OpenAI Developer Docs и изолированный Playwright MCP. Dev Supabase с ограничением на один проект и чтение, а также Blender MCP подключаются в личных настройках по необходимости.
3. Проектные роли `reviewer` и `tester` помогают основному агенту при доступности субагентов. Локальный `Stop` дополняет проверку перед завершением хода после изменения файлов. Для него действуют требования доверия Codex к проекту и к определению хука.
4. Перед коммитом запускаем `pnpm verify` по `AGENTS.md`. GitHub проверяет PR по действующим правилам `main`. Проверка `skills` сохраняет своё имя и теперь валидирует единственный проектный набор скиллов.

## Почему

Оба участника проекта работают по одному комплекту инструкций и инструментов. CI проверяет изменения независимо от того, какие локальные возможности Codex доступны в конкретном сеансе.

Действующие инструкции и примеры подключения находятся в [документации среды](../ai-environment.md). Прежняя настройка и причины её выбора сохранены в [решении 0006](0006-ai-environment.md).
