# 0006. Среда для ИИ: три слоя, CI как единственный жёсткий барьер

Дата: 2026-10-27. Решили владельцы проекта.

> Историческое решение. Рабочую среду заменило [решение 0013](0013-codex-only.md). Описание ниже относится к первоначальной настройке.

## Решение

1. **Правила в файлах, которые читают все.** `AGENTS.md` читают Codex и ChatGPT, `CLAUDE.md` импортирует его для Claude Code.
2. **Инструменты для каждого места запуска отдельно.** `.mcp.json` для Claude Code, `.codex/config.toml` для Codex, коннекторы аккаунта для облачных тредов claude.ai.
3. **CI на GitHub — единственная проверка, которую нельзя обойти.**

Роли: основной агент, субагент-ревьюер (только чтение) и субагент-тестировщик (правит только тесты).

## Почему

Облачные треды проекта на claude.ai загружают из репозитория только `CLAUDE.md` и правила. Субагенты, хуки, скиллы и `.mcp.json` там не работают. У Codex тоже нет хуков и субагентов из репозитория. Поэтому правило «не заканчивать на красном» гарантирует только CI.

Подробности в [редакции документации до перехода на Codex](https://github.com/MeGuRu11/Pupulta-Town/blob/48a02ad972123efe5e74a2698126b88562f5e757/docs/ai-environment.md).
