# 0002. Два трекера: командный и личный

Дата: 2026-10-27. Решили владельцы проекта.

## Решение

- **Командный трекер.** Жёсткие роли: руководитель, исполнитель, гость. Руководитель есть всегда, он создаёт и раздаёт задачи.
- **Личный трекер.** «Личная комната» персонажа: человек пишет задачи себе сам, их никто не видит.
- Личные задачи не просрочиваются.
- Порчу зданий (грязь, граффити, дефект, ремонт, пожар по мере просрочки) вызывают только просроченные командные задачи. Закрытие задачи чинит здание, прогресс не теряется.
- Исполнитель сможет предлагать задачу руководителю, но не в первой версии.

## Что из этого следует

- Права живут в базе (RLS): командные задачи создаёт и назначает только руководитель, личные задачи видит только автор.
- Ступень порчи не хранится, а вычисляется из срока задачи и текущей даты.
