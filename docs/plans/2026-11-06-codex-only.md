# Переход на Codex

## Что меняем

Переводим действующие инструкции, скиллы, субагентов и локальные проверки на Codex по решению владельца. Сохраняем предметные инварианты, правила миграций, ограничения MCP и обязательные проверки GitHub. Исторические документы помечаем как заменённые там, где они описывают прежнюю настройку.

## Файлы

- `AGENTS.md`, `README.md`, документация среды, индекс решений и новое решение.
- `.agents/skills/` для базы и GLB, `.codex/` для MCP, ролей, ограничений команд и проверки перед завершением.
- Workflow CI и проверка единственного набора скиллов. Имя обязательной проверки `skills` сохраняем.
- Удаляем конфиги, дубликаты скиллов и скрипты, которые обслуживали прежнюю интеграцию. Уточняем настройку dev Supabase.

## Проверки

- Тесты валидатора на корректный и некорректный скилл. Проверка обоих скиллов официальным валидатором при доступности.
- Проверка конфигурации и ролей Codex, правил команд через `codex execpolicy check` и сценариев локального хука.
- `pnpm verify`, `pnpm test:e2e`, `git diff --check`, поиск устаревших ссылок в действующих инструкциях.
