# Второй срез. Личные задачи

Первой задачей этого этапа выбираем личный трекер из [плана первого среза](2026-10-28-first-slice.md). В [решении 0002](../decisions/0002-two-trackers.md) закреплены приватность и отсутствие просрочек. За основу берём описанную в [архитектуре](../architecture.md) одну комнату на человека. Её можно открыть сразу после регистрации и из любого города.

1. Закрепить сценарий в Playwright: создать личную задачу до первого города, взять её в работу, завершить, открыть снова и проверить сохранение после перезагрузки. Второй участник того же города ведёт свой список. Личная задача не занимает участок на карте.
2. Добавить миграцию для `personal_tasks` и проверки pgTAP. База связывает задачу с автором и разрешает ему чтение, создание и смену статуса. Проверить эти же операции при входе другим пользователем и без входа.
3. Обновить типы локальной базы, подключить загрузку и запись личных задач, добавить в трекер раздел «Личная комната». Статусы те же, что у командных задач. Срок, размер здания и исполнитель для создания личной задачи не требуются.
4. Проверить миграцию на существующей локальной базе, выполнить `pnpm verify`, тесты базы и браузера, собрать клиент. Декор комнаты и награды относятся к следующим задачам.

## Результат

После входа комната открывается кнопкой «Личная комната» или по адресу [локального трекера](http://localhost:5173/#personal). Список привязан к учётной записи и сохраняется при переходе между разделами. Завершённую задачу можно снова взять в работу. После потери ответа сервера повторная отправка той же формы восстанавливает сохранённую задачу.

| Локальная проверка | Результат |
| --- | --- |
| `pnpm verify` | 179 модульных тестов прошли. Типы, линтер и проверка ассетов прошли |
| `pnpm test:db` | 207 проверок прошли, включая [24 проверки личных задач](../../supabase/tests/personal_tasks.test.sql) |
| `pnpm test:e2e` | 9 сценариев прошли, включая [задачи двух участников и повторную отправку](../../apps/web/e2e/personal-tasks.spec.ts) |
| `pnpm --filter @pupulta/web build` | Сборка клиента прошла |
