# PR5. Город на участке трекера

Основа — ветка интерфейса PR4 и [план первого среза](2026-10-28-first-slice.md). Прототип толпы записан в [PR №16](https://github.com/MeGuRu11/Pupulta-Town/pull/16). Для первой версии используем Three.js и React Three Fiber с простыми формами. Проверка производительности на целевом ноутбуке остаётся открытой.

1. Закрепить тестами привязку объекта базы к клетке, задаче, этапу и порче. Добавить браузерный сценарий с фиксированными seed и временем.
2. В `apps/web/src/scene` построить землю, улицы, модели S и M и жителей. Расположение и размеры брать из базы и общих правил, позиции жителей — из `packages/sim`.
3. Подключить сцену к загруженному городу, часам и подписке PR4. Дать игроку управление поворотом. Сохранить работу трекера при недоступном WebGL.
4. Запустить `pnpm verify`, сборку клиента и браузерные тесты с локальным Supabase. Проверить повторяемость эталонного кадра, смену этапа, просрочку и её исчезновение при закрытии. PR6 отдельно проверит задержку обновления между игроками.

## Результат на локальном ПК

Прошли 155 модульных тестов, 183 проверки базы и 5 браузерных сценариев. Браузер сравнил карту с эталоном при одних часах и seed, проверил поворот туда и обратно, а также создание задачи с отключённым WebGL. В обычном режиме при ширине окна 390 пикселей карта с четырьмя постройками поместилась на экране, поворот и движение жителей работали.

Клиент собрался. Vite предупредил о размере отдельно загружаемого модуля 3D-сцены — 922,63 кБ после минификации, 246,32 кБ с gzip в этом запуске. Пользователь загружает его при открытии города.
