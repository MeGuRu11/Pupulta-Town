## Только для Claude Code

- После правки кода вызывай субагента `reviewer`. Для новой логики, нового правила доступа или исправленного бага вызывай `tester`.
- Документацию библиотек (three, @react-three/fiber, @supabase/supabase-js, colyseus, playwright) бери через MCP Context7, а не по памяти.
- Для задачи больше одного файла сначала план: план-режим или файл в `docs/plans/`.

### В облачном треде проекта на claude.ai

Облачные треды не загружают из репозитория субагентов, хуки, скиллы и `.mcp.json`. Поэтому там:

- проходи чек-лист «Code Review Rules» из AGENTS.md сам, вместо субагента `reviewer`;
- запускай `pnpm verify` сам перед каждым коммитом: хук, который делает это на компьютере, в облаке не сработает;
- MCP-серверы бери из коннекторов аккаунта (Context7, Supabase, Playwright).
