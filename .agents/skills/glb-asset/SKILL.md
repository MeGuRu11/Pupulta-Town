# Модель Blender для Пупульта Town

Сверь модель с [арт-контрактом](../../../docs/art-direction.md). Моделирование выполняй по прямой просьбе. Для проверки и экспорта используй доверенный исходник, относящийся к задаче.

- Модели проекта поставляются в `.glb` (glTF 2.0). В Blender выставь метры, Unit Scale 1.0, примени масштаб и поворот. Фасад в Blender смотрит в −Y. После экспорта фасад смотрит в +Z, вверх направлена +Y.
- Опора в центре основания на уровне земли. Основание здания сверь с сеткой 2 м и следом S/M/L. В одном `.glb` на тип здания этапы строительства и накладки порчи лежат отдельными узлами. Сверь `stage_*`, `decay_*`, `tint_*` и модули этажей L с арт-контрактом.
- Для людей используй общее тело и скелет, сменные детали на том же скелете, не больше четырёх костей на вершину. Сверь имена клипов с арт-контрактом.

## Экспорт и приёмка

В открытой локальной сцене можно использовать уже подключённый Blender MCP. Для экспорта без окна из корня проекта запусти [экспортёр](export_glb.py). Если Blender установлен через Steam и отсутствует в PATH, возьми путь к исполняемому файлу через меню установленных файлов Blender в Steam.

```bash
blender -b "model.blend" --factory-startup --python-exit-code 1 --python .agents/skills/glb-asset/export_glb.py -- "assets/model.glb"
```

Экспортёр проверяет метрические единицы и единичный локальный масштаб мешей. Он печатает габариты и имена корневых объектов для сверки. Проверяй фактический экспорт, включая габариты, опору, иерархию, материалы и клипы.

1. `pnpm check:assets` обходит видимые файлы в `assets/` и проверяет расширение, заголовок GLB и первый JSON-блок с версией glTF. Проверку геометрии, опоры, имён узлов и лимита полигонов делай отдельно. Сверяй лимит, когда он появится в арт-контракте.
2. Если установлен glTF Transform CLI, используй `gltf-transform validate <file>.glb` для проверки спецификации и `gltf-transform inspect <file>.glb` для сводки содержимого. Проверь читаемость и нужные состояния в игровой сцене, когда сцена доступна.
3. Если нужно сжать файл, экспортируй в отдельный выходной файл командой `gltf-transform optimize <in>.glb <out>.glb --texture-compress webp`. Оптимизация может изменить иерархию. Повтори проверку и сравни именованные узлы, материалы и клипы.

Если в облачной или локальной среде Blender недоступен, проверяй уже экспортированный GLB доступными средствами. Когда есть только `.blend`, передай команду локального экспорта и укажи, какие проверки требуют Blender или игровой сцены.

[Команды glTF Transform](https://gltf-transform.dev/cli).
