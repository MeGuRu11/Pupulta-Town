# Изменение базы Supabase

Начни с правил доступа в [AGENTS.md](../../../AGENTS.md) и модели данных в [архитектуре](../../../docs/architecture.md).

1. Создай новую миграцию командой `supabase migration new <name>` в `supabase/migrations/`. Изменения к миграциям из `main` оформляй следующим файлом.
2. Добавь тесты pgTAP в `supabase/tests/` командой `supabase test new <name>`. Для каждого правила проверь разрешённую и запрещённую операции. Создавай фикстуры с разными пользователями и проверяй доступ от роли клиента. При запрете чтения проверяй отсутствие строки, при записи проверяй результат операции или ожидаемую ошибку. Успешный запрос без изменённых строк не подтверждает право записи.
3. Включи RLS на новых таблицах и задай политики нужных операций. Для идентификатора пользователя в политике используй `(select auth.uid())`. Командные задачи создаёт и назначает только руководитель. Личные задачи видит только автор. В тестах сравнивай руководителя с исполнителем, а автора задачи с другим пользователем. Монеты, очки и этапы зданий меняют функции базы.

Тест оборачивай в транзакцию с `begin;`, `select plan(N);`, `select * from finish();` и `rollback;`. После подготовки фикстур переключай роль и UUID перед проверками доступа.

```sql
set local role authenticated;
set local request.jwt.claim.sub = '<uuid пользователя>';
```

## Где проверять

- На машине с Supabase CLI и Docker запусти `supabase start`. Для уже запущенного стека примени ожидающие миграции через `supabase migration up --local`. Запусти `supabase test db --local`.
- В среде без Docker или локальной конфигурации подготовь SQL и pgTAP, укажи, что прогон ещё нужен на локальном стеке или в задании `db` в CI. Успех CI учитывай после фактического прогона.
- Удалённый доступ используй только через MCP с подтверждённым `project_ref` dev-проекта и `read_only=true`. Удалённое применение миграций, включая `supabase db push`, выполняет человек. К production обращается только человек.

[Команды Supabase CLI](https://supabase.com/docs/reference/cli), [тестирование RLS через pgTAP](https://supabase.com/docs/guides/database/postgres/testing-row-level-security).
