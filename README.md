# Пупульта Town

Геймифицированный трекер задач в виде живого 3D-городка в браузере. Проект в разработке.

В веб-трекере можно создать город, пригласить команду и назначить задачи S и M. На 3D-карте каждой задаче соответствует постройка. Когда исполнитель берёт задачу в работу, на фундаменте появляется каркас, а после закрытия виден готовый объект. Над просроченной постройкой появляется значок. Карту можно поворачивать, по тротуарам ходят жители.

Под картой города находится «Лента событий». Она показывает, кто присоединился к команде, заложил фундамент, начал или завершил строительство. При закрытии просроченной задачи там же отмечается восстановление постройки. История ведётся с момента подключения ленты в этой базе. [Как устроена история города](docs/plans/2026-11-23-city-events.md).

После входа можно открыть «Личную комнату» и завести задачи для себя, даже до создания первого города. У личной задачи есть название и статус. Её видит только автор, срока у неё нет. [Правила личного трекера](docs/decisions/0002-two-trackers.md).

При работающем локальном Supabase запустите `pnpm dev` и откройте [трекер](http://localhost:5173). [Подготовка окружения и проверка игры в двух окнах](docs/local-development.md#запуск-командного-трекера).
