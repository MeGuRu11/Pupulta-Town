# Пупульта Town

Геймифицированный трекер задач в виде живого 3D-городка в браузере. Проект в разработке.

После выбора города его 3D-карта занимает всё окно браузера. На ней видны улицы, жители и постройки команды. Сверху показаны название города, число построек и участников, количество завершённых задач и время по Москве. Кнопки справа внизу поворачивают, приближают и отдаляют карту. Каждое нажатие стрелки плавно поворачивает вид на 90°. Повторное нажатие меняет цель во время движения. При системной настройке уменьшенного движения камера сразу показывает выбранную сторону. Масштаб также можно менять колёсиком над картой.

На компьютере разделы открываются из меню слева, на телефоне — из меню у нижнего края. Кнопка «Карта», крестик и `Esc` возвращают к обзору. Нажатие на число завершённых задач открывает список с фильтром «Готово».

| Раздел | Что в нём делать |
| --- | --- |
| Города | Создать или выбрать город, присоединиться по коду или ссылке-приглашению. |
| Новая задача | Руководитель задаёт название, размер S или M, срок и исполнителей. После создания на карте появляется фундамент. |
| Задачи | Смотреть и фильтровать командные задачи. Когда исполнитель берёт задачу в работу, на фундаменте вырастает каркас. После завершения появляется готовый объект. |
| Постройки | Развернуть список объектов с названиями задач, размерами, этапами стройки и признаками просрочки. Список доступен и при недоступной 3D-графике. |
| Участники | Посмотреть состав команды и роли. Руководитель может получить ссылку-приглашение. |
| События | Читать историю города с момента подключения ленты в базе. В ней видны вступление участников, начало и завершение строительства, восстановление просроченных построек. [История города](docs/plans/2026-11-23-city-events.md). |
| Личная комната | Вести собственные задачи без срока. Комната доступна после входа, в том числе до создания первого города. Задачи видит только автор. [Правила личного трекера](docs/decisions/0002-two-trackers.md). |
